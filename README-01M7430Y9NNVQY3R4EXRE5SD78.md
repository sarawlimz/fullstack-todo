# Full Stack To-Do App

Self learning full stack with MERN (MongoDB, Express, React, Node.js) project.

## Tech stack
MongoDB in Docker
Express as backend
React as frontend
Node.JS as runtime environment

## How to run
1. docker run -d -p 27017:27017 --name mongodb mongo
2. cd backend && npm run dev (in the backend directory)
3. cd frontend && npm run dev (in the frontend directory)

## What I learned
I learned how to manage component state in React and how to handle cross-origin resource sharing (CORS) in a full stack application.
